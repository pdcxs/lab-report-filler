# Lab Report Filler

一个帮助你填写实验报告的桌面应用，学生无需接触任何源码。老师设计模板并打包成 ZIP 分发；学生填写文本、插入图片/代码/公式卡片，一键导出 PDF。

[English](README.md) | [中文](README.zh.md)

---

## 系统要求

- **Windows**：Windows 10 或更高版本。无需额外配置。
- **macOS**：macOS 11 或更高版本（提供 Apple Silicon 和 Intel 两个版本）。无需额外配置。
- **Linux**：主流发行版。**需要自行安装 Typst** —— 见下文。

### 在 Linux 上安装 Typst

本程序使用 [Typst](https://typst.app/) 编译器生成 PDF。Windows 和 macOS 版本内置了 Typst；**Linux 版本没有内置**，需要单独安装：

| 发行版               | 安装命令                    |
| -------------------- | --------------------------- |
| Arch Linux           | `sudo pacman -S typst`      |
| Ubuntu / Debian      | `sudo apt install typst`    |
| Fedora               | `sudo dnf install typst`    |
| openSUSE             | `sudo zypper install typst` |
| 任何装了 Rust 的系统 | `cargo install typst-cli`   |

如果发行版仓库里没有 `typst` 包，可以用 `cargo install typst-cli`（需要先装好 Rust）。安装完成后验证：

```bash
typst --version
```

程序启动时会自动检测 Typst，如果没找到会弹出安装说明。

## 安装

前往 [Releases](https://github.com/pdcxs/lab-report-filler/releases) 页面下载对应平台的安装包：

| 平台                            | 安装包                                          |
| ------------------------------- | ----------------------------------------------- |
| Windows                         | `.msi` 或 `.exe`                                |
| macOS（Apple Silicon / M 系列） | `aarch64.dmg`                                   |
| macOS（Intel）                  | `x64.dmg`                                       |
| Linux                           | `.deb` 或 `.AppImage`（需先安装 Typst，见上文） |

**macOS 用户注意**：应用未做代码签名。首次打开时系统可能提示"来自身份不明的开发者"。右键点击应用 → **打开**，或在"系统设置 → 隐私与安全性"里手动允许。

## 学生使用说明

### 1. 获取实验包

老师会发给你一个 **ZIP 文件**（例如 `Java-Programming-Lab.zip`）。不要手动解压——应用会替你解压。

### 2. 选择学生身份

启动应用。欢迎页点击 **I am a Student / 我是学生**。

### 3. 打开 ZIP

有两种方式：

- 点击 **Open ZIP / 打开 ZIP**，选择 ZIP 文件。
- 或把 ZIP 文件直接拖入应用窗口。

应用会弹窗要求你**选择一个空文件夹**，实验包会解压到那里。

> 请选一个空的文件夹，比如在桌面新建一个叫 `JavaLab` 的文件夹。如果文件夹里已经有东西，应用会提示你换一个。

### 4. 填写个人信息

在左侧面板填写：

- **姓名** —— 必须至少包含一个中文字符。
- **学号** —— 4–20 位字母或数字。
- **班级** —— 留空则使用默认值。
- **实验地点** —— 留空则使用默认值。

停止输入 800ms 后自动保存。顶栏徽章会显示 **保存中…** 或 **已保存**。

### 5. 逐个处理实验

用左侧列表切换实验。每个实验页有：

- **实验目的和要求** —— 只读。
- **实验内容** —— 只读。这是你的任务。
- **报告日期** —— 可选。留空则封面使用今天的日期。
- **实验记录** —— 编辑区，通过卡片构建你的报告。

### 6. 用卡片写实验记录

点击 **添加内容** 插入四种卡片之一。每张卡片可以拖动排序、单独删除。

**文本卡片** —— 输入你的文字。支持 Typst 语法：

- `= 标题` 是一级标题，`== 标题` 是二级标题，以此类推。
- `*粗体*`、`_斜体_`。
- `` `行内代码` `` 显示行内代码。
- `$x^2 + y^2 = r^2$` 显示行内公式。
- **每一次回车就是一个新段落。** 你按多少次 Enter，Typst 就分多少段。多个连续空行也可以，只是多出一些空白。
- `#`、`[`、`]`、`@`、`//` 都会被自动转义，可以放心输入。

**图片卡片** —— 选择截图，填写 **标题**（必填），调整显示宽度。标题会作为图片的题注。

**代码卡片** —— 选择语言，粘贴代码，填写 **标题**（必填）。标题会作为代码块的题注。

**公式卡片** —— 用 https://typerino.com/ 编辑公式，粘贴到这里。填写 **标题**（可选）。如果填了标题，公式会自动编号并可被引用；不填则作为无编号的块公式显示。

### 7. 引用其他卡片

每个有标题的图片、代码、公式卡片都可以从文本卡片中引用，语法是 `[[标题]]`：

- `[[标题]]` 引用本实验里**第一个**同标题的卡片。
- `[[标题-uid]]` 引用**指定的**卡片。`uid` 是卡片上显示的 16 位短代码（例如 `abc123xyz456def0`）。
- **如果你有多个同标题的卡片**，`[[标题]]` 会被标记为歧义引用。这时请用文本卡片里的 **Insert Reference / 插入引用** 按钮——它会自动插入 `[[标题-uid]]`，永远指向正确的那一张。

引用最省事的方式是：在文本卡片里点击 **Insert Reference / 插入引用**，从菜单里选标题。应用会在光标处插入精确的 `[[标题-uid]]` 形式。最终生成的 PDF 里，两种形式都会渲染成可点击的"图 1"、"代码 1"、"(1)"。

**你应该引用每一个插入的图片、代码和公式。** 未被引用的卡片会以黄色高亮，如果老师开启了相应检查，导出会被拦截。

### 8. 预览

右侧面板实时显示生成的 PDF 预览，最后一次编辑 800ms 后自动刷新。

### 9. 检查与导出

点击 **Validate / 检查** 检查姓名、学号、以及必需的卡片数量。如果有缺失，会弹窗精确告诉你缺什么。

点击 **Export PDF / 导出 PDF** 生成 `{姓名} - {学号}.pdf`，保存在实验目录中。可以点击顶栏 **Open Project Folder / 打开项目目录** 用文件管理器打开这个文件夹。

### 10. 提交

把 PDF 上传到课程提交系统。

### 小提示

- **切换项目**：点击顶栏 **Open ZIP / 打开 ZIP** 打开另一个实验。
- **重新打开**：应用会记住上次的目录，下次启动自动打开。
- **导出前关闭 PDF**：如果 PDF 正在阅读器里打开，应用会提示你先关闭。

## 老师使用说明

### 1. 选择教师身份

启动应用，点击 **I am a Teacher / 我是老师**。

### 2. 填写课程信息

- **课程名称** —— 课程标题，显示在封面上。
- **指导教师** —— 教师姓名，显示在封面上。
- **默认班级** —— 封面上的班级。学生可以覆盖。
- **默认实验地点** —— 封面上的实验地点。学生可以覆盖。
- **界面语言** —— `中文` 或 `English`。控制学生看到的界面语言。
- **代码语言列表** —— 每行一个。学生会在**代码卡片**的下拉框里看到这些。

### 3. 配置学生字段

姓名、学号、班级、地点的标签和提示文字由界面语言自动决定。你仍然可以配置：

- 姓名最小 / 最大长度。
- 姓名是否必须包含至少一个中文字符。
- 学号格式的正则表达式。

### 4. 添加实验

点击 **+ 添加实验** 添加实验。每个实验需要填写：

- **实验名称** —— 实验标题，显示在封面和实验页顶部。
- **实验目的和要求** —— Typst 源码。写 `+ 内容` 生成编号列表项，或写普通段落。
- **实验内容** —— Typst 源码。规则同上。
- **实验仪器和设备** —— 本实验使用的设备，例如"电脑"。
- **记录指导** —— 每行一条。学生看到的 bullets 提示。
- **编辑框占位提示** —— 编辑区为空时显示的文字。
- **校验规则**：
  - 最少代码卡片数、图片卡片数、文本卡片数。
  - 最少文字字符数（所有文本卡片合计）。
  - 是否要求每个图片/代码/公式卡片都必须通过 `[[标题]]` 或 `[[标题-uid]]` 在文本中被引用。

左侧实验列表可以拖动排序。

### 5. 预览

点击顶栏的 **打开预览**，可以看到完整报告的渲染效果。最后一次编辑 800ms 后自动刷新。

预览使用默认 logo（太原理工大学）。想用其他 logo，点击 **选择 Logo** 选一个图片文件。

### 6. 导出实验包

点击顶栏的 **导出 ZIP**，选择保存 ZIP 的位置。应用会：

1. 创建临时文件夹，包含 `lab.json`、`utils/utils.typ`、`imgs/tyut-logo.jpg`。
2. 压缩成 ZIP 保存到你选择的位置。
3. 清理临时文件夹。

把 ZIP 分发给学生（学习平台、邮件、U 盘等）。

### 7. 草稿持久化

你的编辑会自动保存到应用数据目录下的草稿里。关闭再打开应用，未完成的工作会自动恢复。点击 **新建** 清空当前草稿并从头开始。

### 8. 自定义封面

想换成其他学校的校徽，点击 **选择 Logo** 选一个图片。无论原文件名是什么，都会被写入 ZIP 里的 `imgs/tyut-logo.jpg`。

要自定义封面排版本身，可以在导出后手动编辑 `utils/utils.typ`，然后重新打包。应用目前不支持在界面里编辑 `utils.typ`。
